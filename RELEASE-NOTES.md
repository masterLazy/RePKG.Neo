## What's new

- Supports singleton mode, where the same instance handles additional opened files.
- Supports wallpaper preview (experimental, based on [WebWallGL](https://github.com/oneincase/webwallgl)). We welcome you to share your experience with it so we can decide whether to keep this feature in the formal release! See [#10](https://github.com/masterLazy/RePKG.Neo/discussions/10)

## 更新内容

- 支持单例模式，打开更多文件时由同个实例处理
- 支持预览壁纸（实验性，基于 [WebWallGL](https://github.com/oneincase/webwallgl)），欢迎分享使用体验，以便决定是否在正式版保留此功能！请见 [#10](https://github.com/masterLazy/RePKG.Neo/discussions/10)
